Belajar GitHub: Pengalaman dan Kendala Pertama

Catatan pembelajaran hari ini bersama tim IT dan pembina IT (Pak Zul) mengenai proses mengunggah proyek dari Visual Studio Code ke GitHub. Dalam praktiknya, kami menemukan beberapa kendala yang menghambat proses commit dan push.

TANGGAL Sabtu, 21 November 2026
TOPIK Git & GitHub
KEGIATAN Praktik dan Troubleshooting

Kendala yang Ditemukan

Berikut adalah dua permasalahan yang kami temui selama proses pembelajaran.

01

Aplikasi Desktop Hilang Setelah Restart

Kendala pertama berasal dari komputer laboratorium TKJ. Setiap kali pengguna atau siswa menginstal aplikasi desktop, seperti Adobe Premiere dan aplikasi lainnya, proses instalasi berjalan dengan normal. Aplikasi bahkan dapat dibuka dan digunakan setelah berhasil diinstal. Namun, setelah komputer di-restart, aplikasi yang sebelumnya telah diinstal justru menghilang. Kondisi ini menjadi hambatan karena aplikasi yang dibutuhkan untuk kegiatan pembelajaran tidak dapat dipertahankan setelah komputer dinyalakan kembali.

02

Kendala Saat Pendaftaran Akun GitHub

Kendala berikutnya terjadi pada tahap awal, yaitu ketika mencoba mendaftarkan akun GitHub. Proses pendaftaran beberapa kali mengalami kegagalan setelah percobaan dilakukan secara berulang menggunakan alamat IP yang sama. Percobaan tersebut dilakukan dengan jeda waktu yang sangat singkat, kurang lebih tiga detik. Akibatnya, proses pembuatan akun menjadi terhambat dan kami belum dapat melanjutkan ke tahap berikutnya dengan lancar.

Catatan Pembelajaran

Praktik hari ini menunjukkan bahwa proses belajar menggunakan GitHub tidak hanya berkaitan dengan penulisan kode, tetapi juga melibatkan kesiapan lingkungan komputer dan proses pengelolaan akun. Kedua kendala tersebut menjadi bagian dari pengalaman troubleshooting selama pembelajaran berlangsung.
